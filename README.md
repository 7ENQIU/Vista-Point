# Vista-Point
Официальное название системы — Vista Point. Название означает «точка обзора» или «смотровая площадка» и отражает назначение продукта: дать мастеру настольной ролевой игры единое место, из которого видны устройство кампании, состояние мира, сюжетные связи, доступные возможности, накопленные последствия и текущая игровая ситуация.
