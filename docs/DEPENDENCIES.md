# Зависимости

Проверено 19 августа 2026 года по метаданным npm.

| Пакет | Назначение | Лицензия |
| --- | --- | --- |
| React / React DOM | Пользовательский интерфейс | MIT |
| @fontsource/roboto | Локальный шрифт заголовков и элементов управления | OFL-1.1 |
| @fontsource/roboto-slab | Локальный шрифт основного текста | Apache-2.0 |
| Vite | Локальная разработка и сборка | MIT |
| @vitejs/plugin-react | Интеграция React со сборкой | MIT |
| @types/react / @types/react-dom | Типы React для TypeScript | MIT |
| Vitest | Модульные тесты | MIT |
| fake-indexeddb | Проверка IndexedDB в тестах; не входит в пользовательскую сборку | Apache-2.0 |
| TypeScript | Статическая проверка типов | Apache-2.0 |

Транзитивные зависимости фиксируются `package-lock.json` после установки. Перед релизом требуется воспроизводимый отчёт по их лицензиям и уязвимостям.

Текущая локальная проверка дерева зависимостей обнаружила лицензии MIT, Apache-2.0, OFL-1.1, BSD-3-Clause, ISC и MPL-2.0. MPL-2.0 используется сборочным модулем `lightningcss`; его код не включён в исходный код Vista Point и не модифицируется проектом.
