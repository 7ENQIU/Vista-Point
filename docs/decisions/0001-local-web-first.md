# ADR-0001: локальный web-first каркас

- Статус: принято для первого этапа
- Дата: 2026-08-19

## Контекст

Vista Point должен работать локально и офлайн, не зависеть от аккаунта или облака и сохранять тестируемую доменную логику отдельно от интерфейса. На рабочей машине доступны Node.js и npm, но отсутствует Rust.

## Решение

Первый каркас создаётся на React и TypeScript. Кампании временно хранятся в IndexedDB через интерфейс репозитория. Production-сборка получает service worker для кэширования оболочки приложения.

## Последствия

- Разработка начинается без сервера и дополнительных системных инструментов.
- Пользовательские данные остаются в браузере.
- Очистка профиля браузера может удалить данные, пока не реализован экспорт.
- Нативная оболочка не исключена. После стабилизации модели можно добавить Tauri и SQLite отдельным адаптером.
- Решение следует пересмотреть до распространения приложения среди пользователей.
