# Vista Point 0.2.0

Большое обновление визуального board для Windows.

## Главное

- Единый канвас с графом знаний и графом логики.
- Свободное перемещение карточек и подтверждаемая автоматическая раскладка.
- Масштабирование колесом без прокрутки страницы, перемещение обзора и сохранение положения канвы.
- Автораскладка со штрафом за пересечения и ручные контрольные точки маршрутов связей.
- Быстрое создание и удаление связей, хотбар из десяти пользовательских заготовок.
- Настраиваемая клавиша новой сущности; по умолчанию `N / Т`.
- Сохранённые виды поиска и фильтров графа.
- Краткий попап сущности на графе и единая полноэкранная карточка с данными, состоянием, связями и историей.
- Пользовательские типы сущностей, шаблоны карточек и типизированные пользовательские поля.
- Визуальные логические правила с предпросмотром и обязательным подтверждением значимых последствий.
- Единый журнал событий и безопасные Undo/Redo.
- Удалены статусы «Черновик / Активно», свойство «Видимость» и числовые уровни локаций.

## Установка и обновление

NSIS-установщик содержит автономный WebView2 и устанавливается для текущего пользователя. Windows может показать предупреждение SmartScreen, поскольку проект пока не использует коммерческий сертификат издателя. Updater-артефакт подписан отдельным ключом Vista Point и принимается установленным приложением только после криптографической проверки.

Перед обновлением рекомендуется скачать резервную копию важной кампании. Версии `0.1.0`–`0.1.3` могут найти `0.2.0` кнопкой «Проверить обновления» на главном экране. Кампании и локальные настройки остаются на компьютере пользователя.

## Известные ограничения

- Раскладка карточек хранится локально на конкретном устройстве.
- Фирменный bootstrapper выбора версий пока не входит в поставку.
